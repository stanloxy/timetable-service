## Решения

<!-- Принятые решения с альтернативами и причинами, включая решения по ситуациям, которые задание не регулирует. -->

- WP-01 — транзакции: используем существующий `session_scope` через `async with` вокруг всей операции. Репозитории и загрузчик seed получают сессию без самостоятельного commit; очистка и восстановление при reset входят в одну транзакцию. Отдельный менеджер не вводим: каркас уже обеспечивает commit и rollback.
- WP-01 — seed: обычная загрузка добавляет отсутствующие записи, сохраняя изменённые seed-записи и дополнительные данные. Перезапись при обычной загрузке отвергнута, чтобы повторный запуск не затирал изменения; исходное состояние восстанавливает reset. Seed выполняется отдельно от миграций и напрямую, без people-stub и предметной валидации.
- WP-01 — история переноса: кроме FK и уникальности предшественника запрещаем самоссылку и удаление используемых групп и исходных занятий. Это защищает ссылки и историю; каскадное удаление отвергнуто, поскольку могло бы удалить связанные занятия.
