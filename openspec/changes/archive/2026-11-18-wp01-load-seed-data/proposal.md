# Proposal

## Why

В каркасе пока отсутствуют хранение предметных данных и чтение занятий и групп по идентификатору (FR-04, FR-11). Воспроизводимая схема БД и seed (NFR-02, NFR-03) создадут основу для последующих проверок расписания, интеграции с people-stub и управления занятиями.

## What Changes

- Добавить модели групп и занятий и миграцию Alembic с ограничениями целостности данных (NFR-02).
- Реализовать детерминированную загрузку seed через `just seed` и при `SEED_ON_START=1`. Повторная загрузка должна завершаться успешно без дубликатов; загрузка выполняется напрямую, без вызовов people-stub и предметной валидации (NFR-03).
- Реализовать `POST /__test/reset`: очистка предметных данных и восстановление seed без изменения часов сервиса. Ответ — `204`; при `TEST_MODE=0` — `404 NOT_FOUND` (NFR-03).
- Добавить `GET /lessons/{lesson_id}` и `GET /groups/{group_id}`: ответ `200` с объектом по контракту; для отсутствующего ресурса — `404 NOT_FOUND` (FR-04, FR-11).
- Добавить проверки чтения существующих и отсутствующих ресурсов, загрузки и повторной загрузки seed, reset с сохранением часов и воспроизводимости миграции.

## Capabilities

### New Capabilities

- `timetable-data`: хранение групп и занятий с ограничениями целостности и воспроизводимой миграцией Alembic.
- `seed-data`: детерминированная и идемпотентная загрузка seed, сброс тестовых данных без изменения часов.
- `timetable-read`: чтение группы и занятия по идентификатору с ответами по контракту API.

### Modified Capabilities

Нет.

## Impact

- Приложение `src/app`: модели данных, загрузчик seed, чтение групп и занятий, подключение сброса данных к контексту приложения.
- Alembic: регистрация моделей в metadata и новая миграция предметной схемы.
- API: реализация `GET /lessons/{lesson_id}`, `GET /groups/{group_id}` и `POST /__test/reset` по существующему контракту.
- Тесты: проверки чтения, seed, reset и миграции; обновление проверки reset, которая сейчас ожидает ответ 501.
- Документация: OpenSpec-артефакты и README — решения, AI notes, ограничения и учёт времени.

Seed загружается напрямую в БД, без people-stub и предметной валидации. Такой подход обеспечивает независимое восстановление тестовых данных; загрузка через API создания занятий отвергнута, поскольку связала бы seed с внешним сервисом и реализацией следующих пакетов.
